# Icon sources (bundled locally, not hotlinked)

## Cryptocurrency
PNG icons from [cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons)
(MIT License). Used for BTC, ETH, SOL, XRP, DOGE, USDT, and USDC.

## Flags
ISO flag PNGs from Flagcdn, stored locally for EUR, GBP, USD, JPY, AUD, CAD, CHF.

## Other assets
GOLD, SILVER, NASDAQ, S&P500, and DOW JONES use a clean generic fallback
because authentic trademarked index/commodity marks are not bundled.

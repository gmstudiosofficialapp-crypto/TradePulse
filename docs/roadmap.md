# Roadmap

## Phase 1

Authentication, login, signup, profile, settings, navigation, animations, and
complete UI foundation.

## Phase 2

OTC simulated market, 20 assets, tick engine, 1-minute candle engine, realtime
WebSocket chart.

## Phase 3 (current / complete)

Automatic signal engine (BUY / SELL / NO SIGNAL), demo trading, 1-minute expiry,
WIN / LOSS / DRAW, statistics, and private ground-truth app.

## Out of scope

- Real-money or live trade execution
- External broker connections
- Payment systems
